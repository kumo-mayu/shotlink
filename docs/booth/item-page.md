## 本文（見出しなし）

```
VRChat で撮った写真に QR コードが写っていたら、その中身を Windows の通知で知らせるアプリです。中身が URL なら、通知をクリックするとブラウザで開けます。

Paramroom で相手のアバターに出た QR コードも、カメラで撮るだけで PC に受け取れます。

・VRChat の写真フォルダを自動で監視します。Steam や ShareX など、ほかのスクリーンショットのフォルダも追加できます
・通知領域に常駐します。ウィンドウは設定画面だけです
・開くのは http と https の URL だけです。それ以外はクリックしてもコピーするだけです
・ネットにはつながりません。写真も QR コードの中身もどこへも送りません

Paramroom の配布 zip にも同梱しています。Paramroom をお持ちの方はそちらに入っている物を使っても同じです（最新版はこのページにあります）。
Paramroom：https://kumo-mayu.booth.pm/items/8868240

ソースコードは GitHub で公開しています（MIT ライセンス）。
https://github.com/kumo-mayu/shotlink
```

## 購入前の注意

```
- Windows 10（バージョン 1809 以降）または Windows 11 の 64 ビット版専用です。ARM 版の Windows には対応していません。

- Windows の通知がオンになっている必要があります（「設定 → システム → 通知」）。

- 読むのは、ShotLink を起動してから撮った写真だけです。起動する前からあった写真や、監視を一時停止している間に撮った写真は読みません。

- ソフトの言語は日本語だけです。

- exe には電子署名をしていないので、初回起動時に Windows の警告が出ることがあります。詳細は下の「Windows の警告について」を見てください。
```

## 基本的な使用方法

```
① zip を展開し、ShotLink.exe を好きな場所に置いて起動する
　「ShotLink を起動しました」と通知が出て、画面の右下（通知領域）に ShotLink のアイコンが出ます。ウィンドウは出ません。アイコンが見えないときは、タスクバーの「∧」の中にあります
② VRChat で、QR コードが写るように写真を撮る
③ 数秒で通知が出ます。URL なら通知をクリックすると開き、それ以外の文字はコピーされます

アイコンを右クリックすると、メニューが出ます。
・最近読んだ QR … 読んだ QR をもう一度開く・コピーする（「すべて表示…」で 100 件まで）
・URL をブラウザで開く … オンにすると、通知を待たずにブラウザで開きます
・監視を一時停止 … 止めている間に撮った写真は、再開しても読みません
・写真フォルダを開く
・設定… … 監視するフォルダ、Windows の起動時に起動するか、など

VRChat の写真フォルダ（ふつうは ピクチャ\VRChat）は自動で監視します。VRChat の設定で保存先を変えている場合も、その場所を監視します。ほかのスクリーンショットのフォルダは「設定…」から追加できます。

【消すとき】
① アイコンを右クリック →「設定…」→「通知の登録を消して終了する」を押す（押さずに消すと、Windows の通知の設定に ShotLink の名前が残ります）
② Windows の起動時に起動するようにしていた場合は、先に設定でオフにする
③ ShotLink.exe を消す
④ 設定と履歴も消すなら、%LOCALAPPDATA%\ShotLink のフォルダを消す
```

## 制限について

```
知らない人が見せた QR コードを撮っただけで、知らないページが開かないようにしています。

- 開くのは http と https の URL だけです。それ以外はクリックしてもコピーするだけです
- 「URL をブラウザで開く」は、はじめはオフです。通知で行き先（ホスト名）を確かめてから開いてください
- 同じ URL は続けて撮っても 60 秒に 1 回しか直接開きません（秒数は設定で変えられます）
- 1 枚の写真に QR コードが 4 つ以上あると、通知を 1 件にまとめます。クリックで一覧が開きます（件数は設定で変えられます）
- 「ホワイトリストに絞る」をオンにすると、直接開くのは自分で書いたサイトだけになります
- ネットにはつながりません。写真も QR コードの中身もどこへも送りません。新しいバージョンが出たかどうかも確かめないので、ときどきこのページか GitHub を見てください
```

## Windows の警告について

```
ShotLink.exe には電子署名をしていないため、初回起動時に「Windows によって PC が保護されました」（SmartScreen）と表示されることがあります。

「詳細情報」を押すと「実行」ボタンが出るので、それを押すと起動できます。

気になる方は GitHub のソースコードからご自身でビルドすることもできます。exe は .NET を同梱しているので、別に .NET を入れる必要はありません。
```

## よくある質問

```
Q. 写真を撮っても通知が出ません
A. Windows の通知がオンか（「設定 → システム → 通知」）、メニューの「監視を一時停止」が付いていないかを確認してください。VRChat 以外のスクリーンショットのフォルダは、「設定…」から追加する必要があります。

Q. URL が自動で開きません
A. はじめは、通知をクリックしたときだけ開きます。自動で開くには、メニューの「URL をブラウザで開く」をオンにしてください。同じ URL は 60 秒に 1 回しか直接開きません。

Q. QR コードがたくさん写っていたら、全部開きますか
A. 1 枚に 4 つ以上あると、通知を 1 件にまとめ、はじめは直接開きません。クリックで一覧が開きます。

Q. Paramroom がないと使えませんか
A. いいえ。VRChat の写真に写った QR コードなら、何でも読めます。

Q. 前に読んだ QR コードをもう一度開きたい
A. アイコンを右クリック →「最近読んだ QR」から開けます。「すべて表示…」で 100 件まで見られます。
```
