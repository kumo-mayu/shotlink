ShotLink v{version}
================

VRChat で撮った写真に QR コードが写っていたら、その中身を Windows の通知で知らせるアプリです。
中身が URL なら、通知をクリックするとブラウザで開けます。
Paramroom で相手のアバターに出た QR コードも、カメラで撮るだけで PC に受け取れます。

■ 必要なもの

  - Windows 10（バージョン 1809 以降）または Windows 11 の 64 ビット版
  - Windows の通知がオンになっていること（「設定 → システム → 通知」）


■ 使い方

  1. zip を展開し、ShotLink.exe を好きな場所に置いて起動する
     「ShotLink を起動しました」と通知が出て、画面の右下（通知領域）に ShotLink のアイコンが出ます。
     ウィンドウは出ません。アイコンが見えないときは、タスクバーの「∧」の中にあります
  2. VRChat で QR コードが写るように写真を撮る
  3. 数秒で通知が出ます。URL なら通知をクリックすると開き、それ以外の文字はコピーされます

  初回起動時に「Windows によって PC が保護されました」と出たら、
  「詳細情報」→「実行」で起動できます（exe に電子署名をしていないためです）。

  アイコンを右クリックすると、メニューが出ます。
  - 最近読んだ QR … 読んだ QR をもう一度開く・コピーする（「すべて表示…」で 100 件まで）
  - URL をブラウザで開く … オンにすると、通知を待たずにブラウザで開きます
  - 監視を一時停止 … 止めている間に撮った写真は、再開しても読みません
  - 写真フォルダを開く
  - 設定… … 監視するフォルダ、Windows の起動時に起動するか、など


■ 監視する場所

  VRChat の写真フォルダ（ふつうは ピクチャ\VRChat）を自動で監視します。
  VRChat の設定で保存先を変えている場合も、その場所を監視します。
  Steam や ShareX など、ほかのスクリーンショットのフォルダも「設定」から追加できます。
  起動する前からあった写真は読みません。


■ 安全のために

  - ShotLink が開くのは http と https の URL だけです。それ以外は、クリックしてもコピーするだけです
  - 「URL をブラウザで開く」は、はじめはオフです。知らない人が見せた QR コードを撮っただけで
    知らないページが開かないように、通知で行き先（ホスト名）を確かめてから開いてください
  - 1 枚の写真に QR コードが 4 つ以上あると、通知を 1 件にまとめます（クリックで一覧が開きます。件数は設定で変えられます）
  - 「ホワイトリストに絞る」をオンにすると、直接開くのは自分で書いたサイトだけになります
  - ShotLink はネットにつながりません。写真も QR コードの中身も、どこへも送りません
    （新しい版が出たかどうかも確かめないので、ときどき上の BOOTH か GitHub を見てください）


■ 消すとき

  1. アイコンを右クリック →「設定…」→「通知の登録を消して終了する」を押す
     （押さずに消すと、Windows の通知の設定に ShotLink の名前が残ります）
  2. Windows の起動時に起動するようにしていた場合は、先に設定でオフにする
  3. ShotLink.exe を消す
  4. 設定と履歴も消すなら、次のフォルダを消す
       %LOCALAPPDATA%\ShotLink
