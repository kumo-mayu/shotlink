# 設定の窓の項目

仕様書（`docs/spec.md`）6章の項目の一覧。並びと文言は 2026-10-17 にユーザーが決めた。
見出しを押すと組ごとに畳める（項目が増えて窓が 1000 px を超えたため。最初は全部開いている）。
窓の大きさはドラッグで変えられ、収まらない分はスクロールする。中身に合わせて伸び縮みさせると、畳むたびに横幅まで変わって落ち着かなかった（ユーザー 2026-10-17）。最初は全部開いた中身が入る大きさ（画面より高ければ画面の高さ）で、それより狭くはできない。OK・キャンセルはスクロールの外に置く
字下げした項目は、親の項目が ON のときだけ触れる（「通知をまとめる」だけは、通知の話なので「ブラウザで開く」が OFF でも触れる）。

## QR を読んだとき

- [決定] URL をブラウザで開く（既定 OFF。仕様書 4章）。下に「ON にすると、知らない人が見せた QR の URL も確かめずに開きます」
  - [決定] ホワイトリストに絞る（自分で指定したサイトのみそのまま開きます）（既定 OFF。仕様書 3.6）。「サイトを編集…」で小さな窓を開き、1行に1つ書く。
    入力欄を設定の窓の中に置くと、窓が 1080p の画面に収まらない高さ（1074 px）になったため
  - [決定] 同じ URL は連続して開かない [n] 秒（既定 ON・60 秒。1〜3600 秒。仕様書 3.4）
  - [決定] 一枚に複数ある場合に通知をまとめる [n] 件以上（既定 ON・4 件。2〜99 件。仕様書 3.5）
    - [決定] まとめた場合にもすべての URL を開く（既定 OFF）
- [決定] URL のみ通知する（既定 OFF。URL 以外の QR は履歴にだけ残す）
- [決定] サイレント通知にする（既定 OFF）

「連続して開かない」「URL のみ通知する」「サイレント通知にする」は、`settings.json` では裏返しの名前（`reopenSameUrl`・`notifyNonUrl`・`playSound`）のまま持つ。前の版の設定をそのまま読むため。

## 監視する場所

- VRChat の写真フォルダを監視する（既定 ON。見つけた場所を表示する）
- 追加で監視するフォルダの一覧（追加・削除、チェックでサブフォルダも監視する）。ネットワーク上のフォルダの注意を書く（仕様書 3.1）

## そのほか

- Windows の起動時に ShotLink を起動する（既定 OFF。`HKCU\...\Run` に登録）
- [決定] 履歴を開く（メニューの「すべて表示…」と同じ一覧の窓）
- [決定] 履歴を消す（赤い字。`history.json` に QR の中身が 100 件まで残るため。押すと確かめる）
- [決定] 通知の登録を消して終了する（仕様書 8章）
